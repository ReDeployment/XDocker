# PowerX 实例页面：读取 Setup 连接信息

XDocker 左侧的“PowerX 实例”管理服务器上明确登记的 Docker 实例。它读取该实例当前私有配置中的 PostgreSQL、Redis 和文件存储字段，独立于 PowerX 是否完成 Setup。FRP 回到本机的服务不自动登记为服务器实例。

## 用页面完成 Setup

1. 通过 SSH 私有入口打开 XDocker，使用管理令牌登录，点击“PowerX 实例”。
2. 在 `powerx-dev` 行点击“管理实例”。默认打开“概览”，可切换 PostgreSQL、Redis、文件存储、容器服务、备份标签；顶部下拉框可切换实例。各标签只展示当前实例对应模块的内容，也可用键盘左右方向键切换。
3. 切换到 PostgreSQL 标签，点击“显示密码”，在确认框输入完整实例名 `powerx-dev`，点击确认。密码显示 30 秒；再点击“复制密码”。成功提示“密码已复制”；浏览器拒绝自动复制时会选中密码，可按 Cmd+C / Ctrl+C。
4. 点击“打开 PowerX Setup”，在数据库设置中填页面显示的主机、端口、数据库名、用户名及刚复制的密码。当前 Docker 模板的主机为 `postgres`，用户和数据库名均为 `powerx`；填写后测试数据库连接。
5. 回到实例页并切换 Redis 标签，单独显示并复制 Redis 密码。Setup 的缓存设置使用页面中的 Redis 主机、端口、索引与密码；当前模板主机为 `redis`、端口 6379、索引 0。
6. 切换“文件存储”标签，将本地存储路径和公开地址填入 Setup。管理员账号、邮箱、密码由你在 Setup 中另行选择，再按向导保存、初始化和完成安装。读取连接信息不会自动创建管理员、初始化或重置数据库。

每次只显示一项密码。到期、隐藏、切换模块标签/实例/页面、退出登录或浏览器页面进入后台时，页面密码清空；已复制到系统剪贴板的内容不受页面计时器控制。密码不放入 URL、浏览器 localStorage、普通概览或审计记录；审计只记录哪个实例的哪项密码被查看。响应禁止缓存。

模块选择记录在地址中，例如 `http://127.0.0.1:19080/#instances/powerx-dev/postgres`；刷新可回到 PostgreSQL 标签。容器服务标签只控制当前实例，备份标签也只列出当前实例的备份与操作；左侧“实例备份”仍可查看全部登记实例。

## 配置来源与权限

页面通过 Docker 的只读文件接口，从该实例 backend 容器固定的 `/etc/powerx/config.yaml` 读取白名单字段。先验证 Compose 项目、backend 服务标签及挂载源必须对应 `instances/<实例>/config/`；不提供任意文件路径、命令或 JWT/加密密钥查看接口。不需要降低服务器配置目录 700、文件 600 的权限，也不向 Admin 容器新增配置目录的写挂载。

实例必须先执行过 `apps.sh start`，生成私有配置及 backend 容器。backend 停止时仍可读取配置。无法读取时检查登记、backend 容器与固定配置挂载；CLI 备用方法仍为 `sudo sh scripts/apps.sh setup-values powerx-dev`。

本页面当前提供连接信息读取、按需显示/复制密码、服务状态与备份入口。修改 PostgreSQL 密码仍按[改密流程](README.md#如何修改-postgresql-密码)执行，不在 Setup 中直接填写另一串密码来改变数据库账号。
