# 只推送已有提交验收

本次按用户确认收紧同步策略：现有开发分支的已有 commit 原样推送，保留 SHA、作者和描述；工作区未暂存/已暂存/新文件只提示，不自动提交。移除强制 xdocker-backup 前缀。自动提交工作区及白名单模式本版暂不开放。

本地隔离测试使用真实临时 Git 仓库、bare remote 和 CopyAgent。覆盖原始提交/作者/描述保留、脏工作区和暂存区不变、未跟踪临时文件不发送、已提交临时文件与中间历史密钥阻断、合并历史、元数据秘密隐藏、正常快进/分叉拒绝、源 HEAD 变化、扫描上限及二进制阻断、Agent v1 拒绝、一次性服务授权、迁移保留历史并关闭计划、归档与未知结果保护。敏感检查不等于不存在所有秘密，报告只返回位置与规则。

数据库升级只作用于 XDocker 独立 code-sync SQLite；应用登记与业务数据库不迁移。部署前必须使用旧版本备份 v1 数据库，确认无运行任务，使用已推送准确 SHA，再重启自己的原生实例加载 v2。旧配置全部关闭，既有七个来源保留，未配置凭据或设备时不进行真实推送或分发。运行状态与备份路径在主机私有 deployment-receipt.json 中记录。

回退须停止新执行器并保留新库/回执，恢复对应 v1 备份后再加载旧版本；不允许旧执行器直接使用 v2 库。不会自动修改业务分支、业务配置或业务服务。
